ZombieBuddy Installer

ZombieBuddy Installer is a lightweight background utility built to automate the installation and JVM configuration required for ZombieBuddy. It safely patches your Steam Launch Options and Project Zomboid launch scripts without requiring manual environment setup.

Automated Patching

Applies required -agentlib:zbNative flags to Steam VDF, ProjectZomboid64.json, and batch scripts automatically.

Safe Backups

Creates a .backup of your original configuration files prior to any modifications and never overwrites existing backups.

Zero Setup

Detects Steam paths and active installations seamlessly without requiring manual file placement or environment variables.
