What it handles

One click for the setup steps that are easy to miss.

⌕

Automatic discovery

Detects Steam and Project Zomboid across all configured Steam libraries, including secondary drives.

↯

Complete patching

Updates Steam Launch Options, the normal JSON launcher and the alternate batch launcher with the platform-specific ZombieBuddy Java argument.

✓

Safe and repeatable

Creates non-destructive .backup files, keeps existing options and rolls back a failed installation automatically.

↓

Native files included

Copies the platform-native library and ZombieBuddy.jar from the selected Workshop branch.

◈

LTS and Beta

Detects subscribed versions and lets you choose the stable LTS or the latest Beta branch from the installer.

i

Diagnostics built in

Press F5 in the app to inspect paths, Workshop versions, launcher files and a timestamped installation log.

How installation works

The installer keeps the process visible and reports errors instead of hiding them.

Finds your files

Reads Steam’s library configuration and locates Project Zomboid.

Prepares a snapshot

Records every file it may change so a failed run can be restored.

Installs and patches

Closes Steam, copies the native files and updates all three launch paths.

Confirms completion

Shows each step’s status and confirms when ZombieBuddy is ready.
